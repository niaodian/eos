# D. Operational Pre-Flight Checklist
> decision per item: 采纳 / 不采纳+理由 / 延后+触发条件
- [ ] 关键事件埋点 ↔ 成功指标闭合
- [ ] 权限矩阵 (角色 × 资源 × 操作)
- [ ] 审计范围
- [ ] 回滚预案可执行
- [ ] 灰度维度 + 回退阈值
- [ ] 配额/限流阈值
- [ ] 多租户隔离级别 (如适用)
- [ ] i18n/多区域 (如适用)
- [ ] 容量模型 + 告警阈值
- [ ] 数据生命周期 (保留期/归档/删除；PII 的 GDPR 导出与删除)
- [ ] 高可用/容灾 (冗余、故障转移、备份+恢复演练；按 SLO 需要)
- [ ] Runbook 责任人/升级路径
